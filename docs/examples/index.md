# Example gallery

Each page here is the `README.md` that open-docs generates for a module under
[`examples/`](https://github.com/RemoteRabbit/open-docs/tree/main/examples),
shown as-is. Source links in the tables open the exact lines on GitHub.

- [vpc](vpc.md): a realistic multi-file AWS VPC module with a local child
  module.
- [complete](complete.md): every block type open-inspector understands
  (including ephemeral, check, OpenTofu encryption and provider `for_each`, and
  a `.tf.json` file), plus table edge cases such as pipes, heredocs, Unicode,
  and long values.
- [invalid](invalid.md): deliberately broken configuration for the
  diagnostics table.
